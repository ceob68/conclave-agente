¿QUÉ ES CÓNCLAVE AGENTE?
─────────────────────────
CÓNCLAVE Agente es una aplicación de escritorio para Windows que
ejecuta un equipo de 5 inteligencias artificiales especializadas,
las cuales debaten y colaboran para analizar cualquier problema,
idea o proyecto — completamente sin conexión a internet.

Los 5 agentes son:
  🏛️  Arquitecto     — Estructura y estrategia
  💻  Programador    — Soluciones técnicas y código
  🔒  Seguridad      — Auditoría y vulnerabilidades
  🧪  QA / UX        — Calidad y experiencia de usuario
  📝  Documentador   — Síntesis y documentación

¿PARA QUÉ SIRVE?
─────────────────
• Brainstorming profundo de ideas de negocio o proyectos
• Revisión y análisis de arquitecturas de software
• Evaluación de seguridad de sistemas
• Generación iterativa de documentación técnica
• Resolución colaborativa de problemas complejos
• Cualquier tarea que se beneficie de múltiples perspectivas

REQUISITOS MÍNIMOS
───────────────────
• Windows 10 / 11 (64 bits)
• GPU NVIDIA con mínimo 6 GB de VRAM (recomendado 12-16 GB)
• 16 GB de RAM (32 GB recomendado)
• 30 GB de espacio libre en disco
• Primera vez: conexión a internet para descargar los modelos de IA

INSTALACIÓN
───────────
1. Ejecutar CONCLAVE_Agente_Setup.exe
2. Seguir el asistente de instalación (Siguiente → Instalar → Finalizar)
3. El acceso directo se crea en el Escritorio automáticamente
4. Al primer inicio, la app descarga los modelos de IA (~4-30 GB)
   Asegúrese de tener conexión a internet para este paso
